# Angular Material Adapter - Agent Instructions

If you are an AI Agent operating within this repository, your instructions depend entirely on whether you are **consuming** the Adapter in an external application, or **contributing** to the Adapter by building new components.

Please determine your context and read the appropriate guide:

1. **Consuming the UI Kit**: If you are integrating these components into an application, read `USAGE.md`.
2. **Contributing to the UI Kit**: If you are building, fixing, or modifying components _inside_ this `adapter-angular-material` package, read `CONTRIBUTING.md`.

## Documentation rules

- **Only reference the golden genesis adapter, `recursica-adapter-mantine-v8`.** Do not name or reference any other adapter in this repo's documentation.
- **Keep documentation concise.** Don't include information about current state or future plans unless the developer explicitly asks for it.
